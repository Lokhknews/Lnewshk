L News 編輯後台

在這裡編輯內容，按最下方「發布更新」就會直接更新到你的網站。

連線設定

第一次用？點這裡看怎麼拿 token 到 GitHub 右上角頭像 → Settings → 左側最下方 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。Repository access 選「Only select repositories」揀你的 Lnewshk，Permissions 裡的 Contents 設做「Read and write」，其他保持預設，生成後複製貼上面。 這組 token 只存在你自己電腦的瀏覽器裡，不會上傳到任何地方。
